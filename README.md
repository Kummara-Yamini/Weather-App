# Weather App 🌤️

## 📌 Description

A simple Weather App built using HTML, CSS, and JavaScript that displays real-time weather information, including temperature, humidity, wind speed, and weather conditions for any searched city using the Open-Meteo API.

## 🎯 Purpose

The purpose of this project is to practice JavaScript functions, asynchronous programming, API integration, fetching data, and DOM manipulation by building an interactive weather application.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Open-Meteo API

## ✨ Features

- Search weather by city name
- Display temperature in Celsius
- Show weather conditions with icons
- Display humidity percentage
- Display wind speed
- Handle invalid city names
- Simple and user-friendly interface
- Responsive layout

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.
4. Make sure you have an active internet connection.
5. Enter a city name, such as Hyderabad or Bengaluru.
6. Click the **Get Weather** button to view the weather information.

## 🌐 API Used

**Open-Meteo API:** [https://open-meteo.com/](https://open-meteo.com/)

This project uses the Open-Meteo Geocoding API to find city coordinates and the Forecast API to retrieve current weather data.
